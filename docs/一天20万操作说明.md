# 一天筛 20 万条——团队操作说明（大白话版）

## 〇、程序「打不开 / 被 Windows 拦截」——先看这条（根本办法）

从网盘、微信、QQ、邮箱解压下来的程序，Windows 会给文件加 **「来自其他计算机的锁定」**，双击 exe 容易被拦。

**团队统一这样做：**

1. 解压 **整个文件夹**（不要只解压其中一个 exe）。
2. **优先双击同目录下的 `START_ZhaGouData.bat`**（安装包里已带好）：它会先 **解除锁定**，再启动 `ZhaGouData.exe`。  
3. 仍弹 SmartScreen：点 **「更多信息」→「仍要运行」**（仅用于你们自己发的、可信安装包）。  
4. 公司电脑有严格策略：让运维给 **本程序所在文件夹** 加 **杀毒/Defender 排除项**。

> **想从根上消除黄条/拦截**：需要给 EXE 做 **代码签名证书**（需向 CA 购买），这是商业软件常规做法；未签名时以上 1～2 步是必做的。

## 一、先算一笔账（心里要有数）

- **一天 20 万条** ≈ 平均 **每分钟一百四十条** 左右（全天不停的情况下）。
- 实际上会 **快慢起伏**：有时网站拦得严，会慢；代理好的时候又会快一点。
- 所以：**别把「偶尔变慢」当成坏了**，要看一整小时、一整天的平均。

---

## 二、要买多少代理（socks5）？

**经验说法（够用、省心）：**

| 你打算买的条数 | 大白话 |
|----------------|--------|
| **80～120 条** | 能跑，但要盯，拦多了就得放慢。 |
| **150～250 条** | **推荐**，一天 20 万一般够用、心里不慌。 |
| **300 条以上** | 更稳，适合你想「少操心、少人工干预」。 |

**重要：**  
条数不是唯一标准，**稳不稳**更重要。一堆经常掉线的便宜代理，不如 **一百多条好用的**。

---

## 三、「要开几个窗口」到底指什么？

在你们这个系统里，可以这么理解：

- **窗口 ≈ 同时干活的线路数**（界面上叫「端口」的那一排，选多少个在线，就相当于多少条线一起筛）。
- **不是**让你开很多个 Chrome 窗口对着网页点（那样又慢又乱）。

**建议起步（一天 20 万）：**

- **在线端口（线数）**：先 **10～20 个** 在线试试。
- **任务里「每端口 HTTP 并发」**：先填 **6～8**（不要一上来就拉满）。
- 跑 **半小时～一小时** 看：
  - 如果 **经常卡住、失败变多**：先把并发 **减 2**，或减少几条在线端口。
  - 如果 **很顺、失败很少**：再小幅往上加。

**一句话：**  
代理多、线路稳 → 可以适当多开几条线、并发略高一点；代理一般 → **少开线、先求稳**。

## 四、电脑上第一次要准备什么？

1. **Windows 10/11，64 位。**
2. 解压我们发给你的 **整包文件夹**（不要只拷一个 exe 丢桌面，旁边缺文件会起不来）。
3. 第一次用前，在本机执行一次（只需一次，用来装浏览器内核，给「回退网页查询」用）：

   ```text
   npx playwright install chromium
   ```

   若团队电脑不能联网装，需要运维把 playwright 浏览器缓存拷到相同路径（培训时单独讲）。

4. 配置 **环境变量**（或我们包里自带的 `.env` 模板你改好再启动）：
   - **加密目标**、**密钥**（你们内部已有流程，不在此文档写明文网址）。
   - **批次口令**（和网页里填的 Runner 口令一致）。

## 五、每天怎么干（给团队照着做）

### 早上开工

1. 双击 **`START_ZhaGouData.bat`** 或 **`ZhaGouData.exe`**（从网盘来的包**优先用 bat 启动**）。
2. 看左下角/任务页里 **Runner 地址** 是否是本机（一般是 `http://127.0.0.1:8794`，以你们包内默认为准）。
3. **IP 池**：确认今天要用的代理都在列表里，状态尽量是「可用」。
4. **端口管理**：把今天要用的 **10～20 个端口** 打开（其余可关，减少乱线）。

### 导入数据

1. 去 **数据** 页上传 TXT（一行一个号）。
2. 系统会 **去重**；重复号不会白占额度。

### 开跑

1. 去 **任务管理**：
   - 选数据源；
   - 选好 **在线端口**；
   - 模式建议先用 **混合**（直连快，失败再网页补一下）；
   - **每端口 HTTP 并发** 按上一节的建议填。
2. 点 **启动批次**。
3. 盯着 **进度条** 和 **失败/回退比例**：
   - **失败突然变多**：先别加线，先 **减并发 / 换代理**。
   - **进度长时间不动**：先看是不是 **被拦（429）**，不要当成「没结果」。

### 下班收尾

1. 需要停就点 **停止批次**（会停后端，不是只关界面）。
2. **导出结果**（CSV），自己备份一份到网盘/硬盘。

## 六、培训时三句「必须讲清」的话

1. **被网站拦住 ≠ 这个号没 QQ**——要重试、换线、换代理，不能当无结果。  
2. **代理买够、买稳**，比「把并发拉满」更重要。  
3. **一天 20 万是平均值**，按 **小时进度** 看 ETA，别十分钟一看就改参数。

---

## 七、和开发/运维对接时要说的两个数

团队每天汇报只要两个数：

- **今天实际处理了多少条**（processed）  
- **失败里有多少是「被拦」**（如果是 429 一类，单独说）

有这两个数，才能判断是 **加代理** 还是 **降并发**。

## 八、EXE 包说明

- 开发/运维在 **项目根目录** 执行：
  - `npm install`（第一次或更新依赖后）
  - `npm run build:desktop`（会下载内置 Node、打 `desktop-bundle`、再打出 **Windows 便携 exe**，输出在 `release/`）
  - `npm run verify:desktop-build`（检查 `release` 里是否已有 exe）
- 发布前请按 [`EXE发布前检查清单`](EXE发布前检查清单.md) **至少完整做 2 遍**（其中一遍在另一台干净电脑上）。
- 发布包为 **Windows 便携 exe**（内含界面；Runner 在 `resources\desktop-bundle` 里由内置 Node 启动）。
- 首次部署需按第四节安装 **Playwright Chromium**。
- 若杀毒软件误报，需加白名单（企业环境常见）。

（打包完成后：主程序在 `release\win-unpacked\ZhaGouData.exe`，请**整包**分发该目录，或分发同目录打好的 `release\ZhaGouData-win-x64.zip`。）
